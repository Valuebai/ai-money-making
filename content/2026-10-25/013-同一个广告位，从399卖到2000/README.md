# 同一个广告位，从399卖到2000

## 正文（可直接复制发布）

这个故事我反复看了三遍。一个不是程序员的小哥，一个人加一个Claude Code，做了个帮人挑AI中转站的导航网站。钱全靠卖首页广告位，累计五位数。全程没请人，也没花一分钱买流量。

有意思的是价格：同一个位置，7月底头一回卖，399一个月。后来999。现在挂2000，还是有人买。

他为啥敢一涨再涨？我把它扒出来了，能抄的地方都写细了。

1️⃣ 他挑了同一波需求里轻松的那层
中转站几百家，哪家便宜、哪家稳、哪天跑路，普通人分不清。他没去开中转站，太累，天天养号补封号。他做导航，不碰API，脚本每天跑一遍就完事。吃同一波需求的生意，选对层，辛苦程度差一大截。

2️⃣ 没人愿意干的脏活，反而是护城河
天天盯着几百家站的价格，这事没人爱干。可越脏的活，越容易做出壁垒。他的站每天自动查价格、探活、验真假，数据天天更新。外观抄得走，数据抄不走。他判断一个方向能不能做，先看有没有人已经靠它收到钱。

3️⃣ 定价之前，先把同行扒了一遍
他建了个对标库，写了90多篇笔记，40多个站一页页看。海外同类站，标准位399美元一个月，置顶2500美元，有家重置站4个赞助位699美元一个，卖光了。他的三档价格，就是照着这几家定的。小站也有能抄的：有个检测站月访问才两千，靠一个「降智雷达」的叫法吃到了搜索量。

4️⃣ 涨价以后，随便问问的少了
涨到999的时候，他自己也虚：这下该没人买了吧？结果照样有人买。他的原话：敢不敢收钱，就看你给的东西值不值。数据是真的，来的都是准备充值的准客户，心里自然有底。位置就那么几个，涨价筛掉的本来就是随便问问的人。现在明码标价，不议价，也不拆位置。

5️⃣ 适合谁做，他说得很直白
会用或愿意学Claude Code这类工具、能自己部署网站的；能接受前几个月没收入的；愿意天天维护枯燥数据的。想赚快钱的、技术一点都不想碰的，他劝退。

看完我把这话记下来了：该收钱就收，该涨价就涨，东西值这个价，客户会认。

## 内容要点

1. 选层：同一波需求，他挑轻松的那层——不开中转站，只做导航，不碰 API 不养号
2. 壁垒：没人愿意干的脏活（天天盯几百家站的价格）反而是护城河，数据天天更新抄不走
3. 定价依据：先扒 40 多个同行建对标库，海外同类 399-2500 美元/月当参照系
4. 涨价逻辑：399→999→2000 都有人买；敢不敢收钱看东西值不值，筛掉随便问问的人
5. 适合谁：愿意学 Claude Code 类工具、能接受前几个月没收入、能维护枯燥数据的人
